# 中世纪微缩资产审美规范

风格基准：**精致、色彩鲜明的中世纪手绘游戏感**，温暖繁荣的欧洲乡镇；保留微缩棋盘尺度，不追求照片级或阴暗写实。以《圣殿春秋》的中世纪插画气质为参考，但以用户要求的明亮、鲜艳、游戏感为优先，不照搬其阴暗场景。正常棋盘距离先看清剪影与色块，拉近再看克制的结构细节。

参考依据：[Daedalic 官方介绍的手绘背景方向](https://daedalic.prezly.com/new-game-based-on-the-pillars-of-the-earth-begins-this-summer)。这是风格参考，不使用或复制游戏素材。

## 可观察标准

| 维度 | 应呈现的效果 | 需要修正的表现 |
| --- | --- | --- |
| 轮廓与比例 | 建筑、树木、资源在棋盘尺度可辨；形体适度夸张、轮廓饱满、主次分明 | 密集写实碎片；近看细节很多，缩小却混成一团；模型互相遮挡 |
| 构造 | 木梁支撑合理，屋顶有厚度、出檐和层次，门窗嵌入墙体，建筑稳落地面 | 漂浮、穿插、纸片屋顶、过粗倒角或机械拼接的基本体 |
| 材质 | 以哑光、柔和明暗和绘画式色块区分木、石、草；材质可在 GLB 中复现 | 照片贴图、写实污渍、塑料反光、强凹凸；依赖 Blender 独有着色器 |
| 色彩 | 主体绿鲜明，深翠阴面＋草绿主体＋黄绿少量亮部；暖赭木材、金棕土路，资源与玩家色清楚 | 灰绿滤镜、黑压压的阴影；全画面同饱和度、荧光绿或高光过曝 |
| 细节 | 优先结构与大色块，再补少量有节奏的木纹、叶簇、瓦片；细节服务游戏可读性 | 用上万碎叶、裂纹或微噪声堆砌“精致”；远看杂乱 |
| 植被 | 树冠先有清楚的不对称大体块，再点缀少量叶簇；允许概括但不机械堆球 | 写实碎叶云、规则球串/圆锥堆叠、明显复制阵列；遮住数字或建造位置 |
| 整体一致性 | 地块、建筑、棋子共享尺度、材质语言和细节密度 | 单个模型精细却与整盘风格不一致；部分模型过度写实或粗糙 |
| 组合兼容性 | 地块接缝齐平，挂载对象落点稳定且保留净空 | 地形越界、数字与强盗重叠、建筑道路被装饰侵占 |

## 固定评审方法

- **棋盘视角**：按实际对局倾角与距离观察，并放入邻接地块、数字牌及棋子对照；检查资源辨识、数字可读、玩家色和物体遮挡。
- **近景**：检查倒角、构件厚度、材质过渡、贴图尺度及磨损位置；细节服务于主体造型。
- **侧面**：检查落脚、悬空、穿插、接缝、屋顶与树冠体积，以及挂点净空。
- 采用固定中性光照、曝光、镜头和显示模式比较版本；另用游戏光照检查整体氛围。展示性景深、浓雾和强辉光不能掩盖缺陷。
- 先看缩小到棋盘尺寸的色彩与轮廓，再检查近景；鲜艳应来自资产配色，不能只靠改变灯光、曝光或滤镜。
- Blender 中好看仍需复核导出的 GLB；资产预算超限时先减少不可见细节与冗余材质，保留轮廓、结构和主要材质差异。

所有适用维度必须有可见证据；明显塑料感、结构穿插、数字不可读、占用冲突或风格失配均视为未通过。无法看到的项目标为未检查，不自行推断通过。
