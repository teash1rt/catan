# 桌面地图展示样板

入口：`pnpm dev`。只做本地展示，不连接服务端、不创建权威游戏状态。基础版数量参考 [官方规则](https://www.catan.com/sites/default/files/2021-06/catan_base_rules_2020_200707.pdf)；不是固定的新手开局图。

## 当前行为

- 固定半径 2 的六角岛：19 地块、72 共享边、54 共享顶点；30 海岸边自动装配岸段和凹凸角。
- **刷新地图**：重排森林/麦/羊各 4、砖/石各 3、沙漠 1；重排 18 数字牌（2/12 各 1，其余 3–11 除 7 各 2），6/8 不相邻；沙漠无数字，强盗跟随沙漠。
- 9 港口保持固定位置与类型：4 通用 3:1、五类资源 2:1 各 1。检查外海朝向、港口之间及港口与陆地的占地。
- 中键拖动旋转/俯仰、右键沿地面拖拽、滚轮围绕鼠标指向缩放；点击地图后 WASD/方向键平移、Q/E 旋转。左键预留选择交互，不拖动镜头。可选道路/村庄/城市示例和四种玩家颜色，示例不代表合法开局。
- 数字与概率点为运行时透明纹理，不修改空白底座 GLB；数字与强盗读取挂点。港口牌仍为固定方向，不自动朝镜头。

## 代码边界

| 位置                                            | 责任                                                                                                  |
| ----------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `packages/protocol/src/index.ts`                | 地图配置的共享类型与 Zod 边界校验；无模型链接                                                         |
| `packages/game-core/src/map.ts`                 | 整数格点拓扑、经典配置、种子驱动的确定性生成；无 Three.js                                             |
| `apps/desktop/src/renderer/src/board/layout.ts` | 布局转模型变换、海岸/港口装配与占地检查                                                               |
| `board/assets.ts`                               | 从根目录 `assets/*/model.glb` 获取资产，目录名映射至 Vite 打包 URL；缓存 GLB，不打包同目录的 `.blend` |
| `board/assembly.ts` / `numbers.ts`              | 挂点、玩家材质隔离、实例化、动态数字                                                                  |
| `board/camera.ts`                               | 策略游戏镜头：输入目标、地面投影、时间相关缓动、边界与事件清理                                        |
| `BoardScene.tsx` / `App.tsx`                    | 光照、镜头、UI；不硬编码资源/数字分配规则                                                             |

模型遵循[现有契约](modular-asset-plan.md)，不再做 Z-up 补旋转。重复网格按几何体＋材质分批实例化；共享资源跨刷新保留。替换布局时**先从场景移除旧对象，再释放实例缓冲和数字纹理**，避免旧帧重新上传已释放资源。空闲按需渲染。

## 镜头调整（2026-10-19）

参考俯视建造游戏的操作分工，不声称复刻《冰汽时代》的具体参数。旋转、拖拽、缩放与复位使用按时间计算的指数缓动；停止后不持续请求帧。中键有 3 px 防误触，俯仰离竖直 25°–60°，缩放 0.7–3.5，观察中心限制在地面、距岛心 16 单位内。地面边界优先于光标锁定，避免缩放或拖拽丢失岛屿。

自动测试覆盖 30/60/144 Hz 缓动一致性、地面拖拽、光标缩放最终落点、极限值、复位、输入映射和取消/清理；这些不代替实际鼠标手感验收。

本轮 `pnpm lint`、桌面端类型检查、10 项测试及桌面构建通过；Computer Use 已在构建版检查键盘旋转/平移、滚轮缩放和复位，模型正常显示。当前原生拖拽工具不能指定中键/右键，相关拖拽只完成自动输入与数学测试，真实鼠标手感待人工确认。

## 固定展示比例与精简界面（2026-10-20）

用户确认采用 **x=0.40（新增缝宽）、y=5.0（村庄/城市倍率）**，由 `board/layout.ts` 的 `BOARD_PRESENTATION` 统一提供。启动、刷新、换色、棋子显隐和视角复位均不改变比例；移除滑杆、参数还原和对比样板入口。

地图铺满窗口，删除顶部横幅、资源侧栏、介绍文案和底部状态栏。仅保留右上角可折叠悬浮调试面板：刷新地图、复位视角、棋子显隐、玩家换色、种子与绘制/几何/纹理计数；收起不重建场景或移动镜头。

地块本身不缩放，数字与强盗随原挂点；中心距乘 `1+0.4/(3√3)`，道路沿长轴适配，基座、海岸、港口及交易牌沿水平面适配，缝隙使用中性铺地。正式 `.blend/.glb` 和玩法配置不变。用户确认的是观看比例，**不等于建筑净空、道路端点、港口承托与全部遮挡组合已验收**，后续仍需精修。
